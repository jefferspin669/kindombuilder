# Kingdom Builder — The World of Aetheria



## Run

```bash
cd aetheria
python3 -m http.server 8080
```

Then open:


| Control | Action |
|---|---|
| Click unit / tile | Select / step |
| WASD / arrows | Move |
| F | Found city |
| G | Gather |
| Tab | Next unit |
| Enter | End turn |

Optional: `npm run smoke`
