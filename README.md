# kindombuilder

HTML/CSS/JS testing build of **Kingdom Builder: The World of Aetheria**.

## Live

- Site: https://jefferspin669.github.io/kindombuilder/
- Game: https://jefferspin669.github.io/kindombuilder/aetheria/game.html

Click **Begin Reign** to start.

## Local

```bash
cd aetheria
python3 -m http.server 8080
```

Open http://localhost:8080/game.html and click **Begin Reign**.
